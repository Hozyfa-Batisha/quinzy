# 📖 أسئلة وتدريبات كتاب الفائز: تطبيقات الذكاء الاصطناعي في الحياة اليومية والصناعة (Lesson 1-3)
*المصدر: كتاب الفائز في البرمجة والذكاء الاصطناعي - الصف الثاني الثانوي بكالوريا 2027*

## 🟢 السؤال الأول: اختر الإجابة الصحيحة من بين الخيارات التالية (MCQ)

1. **ما الخدمة التي تتنبأ بتفضيلات واهتمامات المستخدم استناداً لبيانات سلوكه ومشترياته السابقة وتكتشف الأنماط؟**
   - [أ] التعرف على الوجوه
   - [ب] المساعدات الصوتية
   - [ج] الترجمة الآلية
   - [د] أنظمة التوصية (Recommendation Systems)

2. **ما التقنية المستخدمة في تطبيق يتعرف على الأوامر المنطوقة، يفهمها، ثم ينفذها على الهاتف الذكي؟**
   - [أ] أنظمة التوصية
   - [ب] المساعدات الصوتية (Voice Assistants)
   - [ج] الترجمة الآلية
   - [د] التعرف على الصور

3. **ما التقنية المستخدمة لتحويل وتلخيص النصوص والمحادثات تلقائياً بين اللغات المختلفة دون مبرمج بشري يترجم حرفياً؟**
   - [أ] التعرف على الوجه
   - [ب] المساعدات الصوتية
   - [ج] الترجمة الآلية (Machine Translation)
   - [د] الصيانة التنبؤية

4. **أي مما يلي يُعد تطبيقاً مباشراً على تقنية التعرف على الوجوه (Face Recognition) في حياتنا اليومية؟**
   - [أ] فتح الهاتف الذكي بمجرد النظر للكاميرا
   - [ب] تشغيل التلفاز بالريموت
   - [ج] كتابة مقال صحفي
   - [د] شحن الرصيد

5. **أي المنصات التالية تعتمد بشكل جوهري على أنظمة التوصية لترشيح مقاطع الفيديو والمنتجات للعملاء؟**
   - [أ] YouTube وAmazon وSpotify
   - [ب] الآلة الكاتبة
   - [ج] قارئ الأقراص
   - [د] آلة الحساب التقليدية

6. **أي التطبيقات التالية يمثل نموذجاً شهيراً للمساعدات الصوتية الذكية؟**
   - [أ] Siri وGoogle Assistant
   - [ب] DeepL
   - [ج] Excel
   - [د] Word

7. **أي الخدمات التالية تعتبر مثالاً بارزاً على الترجمة الآلية الذكية؟**
   - [أ] Google Translate وDeepL
   - [ب] Siri
   - [ج] Spotify
   - [د] Amazon

8. **في أي قطاع يتم استخدام الذكاء الاصطناعي لتحليل صور الأشعة السينية (X-rays) والمقطعية للكشف المبكر عن الأورام؟**
   - [أ] قطاع الزراعة
   - [ب] قطاع التصنيع
   - [ج] قطاع الخدمات اللوجستية
   - [د] قطاع الرعاية الصحية (Healthcare)

9. **في أي مجال صناعي يُستخدم الذكاء الاصطناعي للتنبؤ بموعد الحصاد المثالي واكتشاف الآفات والأمراض في النباتات؟**
   - [أ] قطاع الزراعة (Agriculture)
   - [ب] قطاع التصنيع
   - [ج] قطاع الرعاية الصحية
   - [د] قطاع الخدمات اللوجستية

10. **ما المصطلح الذي يُطلق على استخدام الذكاء الاصطناعي والتنقل بالبيانات للتنبؤ بأعطال الآلات قبل وقوعها في المصانع؟**
    - [أ] التصنيع التقليدي
    - [ب] الصيانة التنبؤية (Predictive Maintenance)
    - [ج] أتمتة الجودة الحرفية
    - [د] الصيانة الفجائية

11. **ما المجال الصناعي الذي يستخدم الذكاء الاصطناعي في تحسين وتخطيط مسارات شاحنات التوصيل (Route Optimization)؟**
    - [أ] قطاع الخدمات اللوجستية (Logistics)
    - [ب] قطاع الزراعة
    - [ج] قطاع الرعاية الصحية
    - [د] قطاع التعليم

12. **ما البيانات التي تعتمد عليها برامج الصيانة التنبؤية داخل المصانع لتقدير احتمال عطل المعدات؟**
    - [أ] قراءات الاهتزاز ودرجة الحرارة والسرعة من المستشعرات
    - [ب] أسماء العمال وصورهم
    - [ج] نصوص الإعلانات
    - [د] أسعار المنتجات في السوق

13. **ما الذي يبرع فيه الذكاء الاصطناعي ويتميز به بشدة مقارنة بالبشر؟**
    - [أ] اكتشاف وتصنيف الأنماط في البيانات الضخمة المعقدة والتنبؤ الإحصائي
    - [ب] إبداء التعاطف وإصدار الأحكام الأخلاقية
    - [ج] تحمل المسؤولية الجنائية
    - [د] احترام الخصوصية تلقائياً دون برمجة

14. **ماذا يُسمى العيب الناتج عن تقديم الذكاء الاصطناعي لمعلومات مغلوطة تظن أنها حقيقة بثقة عالية؟**
    - [أ] التوصية الذكية
    - [ب] الهلوسة (Hallucination)
    - [ج] التنبؤ السليم
    - [د] الترجمة الدقيقة

15. **ما المفهوم المعبر عن غياب الشفافية وعدم معرفة السبب الدقيق وراء اتخاذ الذكاء الاصطناعي لحكم معين؟**
    - [أ] الصيانة التنبؤية
    - [ب] مشكلة الصندوق الأسود (Black-box Problem)
    - [ج] نظام التوصية
    - [د] التعرف على الوجوه

16. **أي المواضيع التالية تتطلب الحذر الشديد والإشراف البشري الكامل ولا يصح تركها للآلة بمفردها؟**
    - [أ] البحث عن الأنماط في الصور
    - [ب] القرارات الأخلاقية، التعامل مع الخصوصية، والتشخيص النهائي للمرضى
    - [ج] حساب المجموع الحسابي
    - [د] ضغط الملفات

17. **ما السبب الذي قد يجعل أحكام الذكاء الاصطناعي غير دقيقة أو متحيزة ضد فئة معينة؟**
    - [أ] وجود تحيز أو عيوب في بيانات التدريب (Training Data Bias)
    - [ب] جودة الشاشة
    - [ج] حجم ذاكرة الرام
    - [د] نوع لوحة المفاتيح

18. **من هو الفاعل الواجب تأكيده للتشخيص الطبي النهائي قبل البدء في علاج المريض؟**
    - [أ] تطبيق الذكاء الاصطناعي بمفرده
    - [ب] الطبيب البشري المختص (Human Doctor)
    - [ج] المبرمج الذي كتب الأكواد
    - [د] الشركة الصانعة للجهاز

19. **متى تزداد الحاجة الماسة للإشراف البشري (Human-in-the-loop) على قرارات الذكاء الاصطناعي؟**
    - [أ] عندما تكون نتائج القرار ذات أثر عالي وحساس وتؤثر على حياة وصحة وأموال الأشخاص
    - [ب] عند تشغيل لعبة بسيطة
    - [ج] عند الاستماع لمقطع موسيقي
    - [د] عند البحث عن كلمة في معجم

20. **ما الضوابط الأساسية التي يجب مراعاتها عند ادخال الذكاء الاصطناعي في أي صناعة؟**
    - [أ] الأخلاقيات، الخصوصية، المسؤولية، وجودة البيانات والتحقق البشري
    - [ب] خفض جودة البيانات
    - [ج] إلغاء دور الإنسان تماماً
    - [د] عدم فحص الأخطاء

## 🟡 السؤال الثاني: ضع علامة (✔) أمام العبارة الصحيحة وعلامة (❌) أمام العبارة الخاطئة

1. ( ) الذكاء الاصطناعي ممتاز ومتفوق في اكتشاف وتصنيف الأنماط في البيانات الضخمة المعقدة.
2. ( ) لا يوجد أي دور للذكاء الاصطناعي في التطبيقات والخدمات التي نستخدمها في حياتنا اليومية.
3. ( ) تستخدم أنظمة التوصية السلوكيات والمشتريات السابقة للمستخدم لاقتراح محتوى يهمه.
4. ( ) يستطيع المساعد الصوتي تحويل الصوت إلى كلام، فهم المعنى، وتنفيذ الأمر المطلوبة.
5. ( ) الترجمة الآلية تعتمد على مبرمج بشر يترجم كل جملة في العالم يدوياً مسبقاً.
6. ( ) تُستخدم تقنية التعرف على الوجوه لفتح الهواتف وتحديد الأشخاص في الصور.
7. ( ) لا يمكن تطبيق الذكاء الاصطناعي في مجال الرعاية الصحية أو تحليل صور الأشعة.
8. ( ) تساعد تقنيات الذكاء الاصطناعي الأطباء في اكتشاف علامات الأمراض من الصور السينية والمقطعية.
9. ( ) يقتصر دور الذكاء الاصطناعي في الزراعة على سقي النباتات بالماء فقط.
10. ( ) تُساعد الخدمات اللوجستية الذكاء الاصطناعي في تحديد وتحسين مسارات شاحنات التوزيع والتوصيل.
11. ( ) تتيح الصيانة التنبؤية التنبؤ بأعطال المعدات في المصانع قبل حدوثها لتفادي الخسائر.
12. ( ) الذكاء الاصطناعي خالي من الأخطاء ويضمن دائماً إعطاء نتائج عادلة وصحيحة 100%.
13. ( ) تظهر نتائج متحيزة أو خاطئة من الذكاء الاصطناعي إذا كانت بيانات التدريب غير متوازنة أو متحيزة.
14. ( ) الهلوسة هي إخراج الذكاء الاصطناعي لمعلومات مغلوطة تبدو فصيحة ومقنعة للغاية للمستخدم.
15. ( ) جمع واستخدام البيانات الشخصية للمستخدمين في الذكاء الاصطناعي لا يثير أي مخاوف حول الخصوصية.
16. ( ) تُشير مشكلة الصندوق الأسود إلى صعوبة فهم وتتبع المسار المنطقي الداخلي لقرار الشبكة العصبية.
17. ( ) يمكن القبول بترك القرارات الأخلاقية والقانونية المصيرية للذكاء الاصطناعي دون مراجعة بشرية.
18. ( ) تشتد أهمية وجود العنصر البشري في الحلقة كلما ارتفعت خطورة القرار وأثره على المجتمع.
19. ( ) يساعد الذكاء الاصطناعي في المصانع على فحص جودة المنتجات واكتشاف عيوب التصنيع تلقائياً.
20. ( ) يُعد الحفاظ على الخصوصية والشفافية وتحديد المسؤولية من أركان استخدام الذكاء الاصطناعي المسؤول.
